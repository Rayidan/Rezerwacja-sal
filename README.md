System rezerwacji sal szkoleniowych - kod aplikacji

Wymagania:
- Python 3.x (nie sa wymagane zadne dodatkowe biblioteki)

Uruchomienie programu:
1. Otworzyc terminal w tym folderze.
2. Wpisac: python rezerwacja_sal.py
3. Korzystac z menu wyswietlanego w konsoli.

Uruchomienie testow:
python testy.py

Pliki:
- rezerwacja_sal.py - glowny program (menu, obsluga rezerwacji)
- testy.py          - testy funkcji sprawdzajacej dostepnosc sali i nadawania numeru rezerwacji
- sale.csv          - lista sal dostepnych do rezerwacji (dane poczatkowe)
- rezerwacje.csv    - plik z rezerwacjami, tworzony automatycznie po dodaniu pierwszej rezerwacji
